石间 · 磁盘空间首个 GitHub 公开发布版。

## 下载与运行

1. 下载下方 Assets 中的 **Shijian-Windows-x64-v0.3.1.zip**。
2. 右键 → 全部解压，进入 **石间-Windows** 文件夹。
3. 双击 **石间.exe**。请保留 resources、locales 和 DLL，不能只取出 EXE。

Windows x64 免安装便携版，无需 Node.js 或 Python。已在 Windows 11 x64 的隔离测试目录中验证扫描、缓存重启与手动刷新。

磁盘扫描离线可用；AI 清理需在「AI 清理 → API 设置」中配置自己的 DeepSeek API Key。未包含任何个人密钥或磁盘缓存。AI 建议由用户确认后移入回收站。

此包未做代码签名。SHA256SUMS.txt 可用于核对文件完整性。Source code 是开发源码，不是安装包。
