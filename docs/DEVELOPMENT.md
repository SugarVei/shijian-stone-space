# 石间

Windows 磁盘空间可视化软件，以及共用同一套 React 页面的网站设计预览。

网站中央提供「石头布局 / 3D 热力柱」两种可切换的视图，默认显示恢复的毛玻璃石头布局。石头按当前磁盘的五类已用空间显示，面积按容量分配，点击仅查看分类详情，不进入未核实的示例文件夹；保留流光边框与鼠标柔光。网页石头、容量条、图例使用同一组低饱和中性色，颜色也集中在 DATA.categories；3D 热力柱继续使用灰到红的数值渐变。独立单文件为 `public/disk-heatmap.html`，文件顶部 `DATA` 是该图和网页容量分类的唯一数值来源，使用用户提供的容量。Three.js 与 OrbitControls 通过同版本的 CDN 引入；图形在独立的同源 iframe 内运行，以兼容托管平台的页面脚本。顶部栏、左侧磁盘入口和 AI 清理浮层保留，网站不再提供旧示例文件夹钻取。桌面版文件夹扫描与鹅卵石页面保持原实现。

分类合计与已用、已用加可用与总容量均在绘图前校验，不一致则明确报错。支持拖动旋转、滚轮与双指缩放、Perspective/Top view 相机过渡、GB/% 柱高与配色过渡、逐柱悬停和详情、Reset view。占该盘比例的分母为该盘总容量，占全部已用比例的分母为三盘已用总计。未提供历史数据，因此上周对比与变化显示「—」。

`scripts/verify-heatmap.cjs` 检查实际 WebGL 点击全部分类柱、详情数值、动画、旋转缩放、双指手势、手机标签、原页面控件和错误数据提示。设置 `HEATMAP_URL` 可检查部署版本。单文件直接打开需要联网加载 CDN，正常运行需要支持 WebGL。

- 桌面：`release/石间-Windows/石间.exe`，完整目录保留在一起即可运行。
- 实时设计预览：双击 `启动实时预览.cmd`，打开 `http://127.0.0.1:5186`；网页与开发版软件同步热更新。
- 线上网站：https://shijian-stone-space.twxyforl.chatgpt.site 。已按用户要求公开访问，网站使用示例数据，不读取本机磁盘。

支持真实容量、文件夹递归扫描与取消、磁盘切换、选中查看、双击进入、返回、搜索、资源管理器打开目录、选中边框环绕流光、鼠标聚光和移动布局。后台工作线程扫描，布局也使用独立工作线程。

0.3.0 起，完成的磁盘/目录扫描会压缩保存到当前用户的 `scan-cache-v1` 缓存目录。下次启动先加载上次结果，再独立查询最新磁盘容量，不自动重扫完整磁盘；已浏览并完成扫描的文件夹也可直接读取缓存。完整扫描使用小批量并发读取文件元数据，减少逐文件串行等待。缓存会校验磁盘卷序列号，不将同盘符的替换磁盘当成原磁盘。

缓存始终标注上次扫描时间。程序运行时监测所查看目录的变化，并在启动时检查根目录和前 200 个直接子项的元数据；发现变化显示「有变化 · 待刷新」。为了避免每次打开仍消耗全盘扫描资源，不自动递归检查全部历史数据，关闭程序期间发生的深层变更可能无法由轻量检测发现。需要完整最新结果时点击右上角刷新；刷新期间保留旧石头分布并显示「后台刷新」。第一次使用及损坏/不匹配的缓存仍需完整扫描一次。

石头面积按当前层级已读取文件的逻辑字节数分配。最多同时显示 70 个石头，其余合并为可点选的“其他 N 项”；零字节项目不占可视面积。容量条显示系统报告的已用/总量和可用空间；分类由目录名称推断，未读取/系统保留部分归入“其他”。压缩、硬链接、系统元数据会导致逻辑大小与系统磁盘占用不同。无法访问的项目和链接均跳过，并显示读取不完整状态。

磁盘扫描离线运行。点击「AI 清理」后，可使用 DeepSeek 分析清理候选；仅发送候选文件的相对路径、大小和修改时间，不上传文件内容。API Key 在桌面版的 API 设置中输入，由 Windows safeStorage 加密保存在当前用户的应用配置目录，不进入源码、网页或便携包。模型默认 DeepSeek Flash，接口固定为官方 `https://api.deepseek.com/chat/completions`。

AI 建议在石头上显示绿色标记，并在面板里给出具体文件、大小和原因。默认不勾选任何项目；由用户选择、经原生确认框确认后逐项移入回收站，不永久删除。删除前后重新核对路径、文件身份、大小、修改时间、链接状态和本地清理规则。变化或被占用的文件保留并报告失败，系统目录、凭据、链接、文档和最近七天修改的文件不作为清理候选。

只分析扫描完成后筛选的旧临时文件、日志及缓存，最多向 API 提交前 160 个候选；超出时提示进入子文件夹继续，未读取的内容不会宣称安全。AI 建议不能保证无害，用户需确认文件已不再需要。网站仅演示建议、标记和确认流程，不接收密钥、不连接真实 API、不操作本机文件。

从缓存进入 AI 分析时，会先重新核对候选文件的身份、大小、修改时间及清理规则，再发送元数据；清理前仍会重复核验。软件清理后将对应磁盘缓存标为待更新并刷新当前目录，保留其他历史视图以便快速启动。

开发：Node 24、`npm install`、`npm run dev`。构建：`npm run build`；打包：`npm run package`；统计和面积测试：`npm test`。

`scripts/verify-ui.cjs --desktop` 使用 Playwright 和本机 Chrome 验证网页交互、动画、响应式与桌面扫描。可通过 `STONE_PLAYWRIGHT_MODULE` 指向已有 Playwright 安装。

`scripts/verify-cleanup.cjs` 验证网页清理流程和桌面扫描→模拟 AI→用户确认→回收站适配器的完整流程，只处理测试临时文件。`npm test` 覆盖系统目录保护、AI 输出校验、低置信度处理、取消、文件变化拦截和回收确认。

`scripts/verify-startup.cjs` 验证首次扫描→退出→重启读取缓存、缓存命中不启动递归扫描、文件变化提示、手动刷新与界面保留，并输出测试目录的启动/缓存读取耗时。

设计参考和实现对照见 `docs/DESIGN.md`，实际渲染截图见 `docs/stone-layout.png`、`docs/mobile-layout.png`。
